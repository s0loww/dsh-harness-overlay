# Капитан Дизель: локальные пиратско-1Сные реплики

`airules-dsh-captain-companion` добавляет реплики существующему спрайтовому
Капитану Дизелю, норвежскому лесному коту. Это не модель Live2D и не генерация
ответов через LLM. Второй аватар не создаётся.

## Интеграция

Плагин читает официальный companion provider установленного
`@michengai/dsh-codex-pet` 1.0.12: `window.dshPet` v1,
`getSnapshot()`, `subscribe()`, события `dsh-pet-ready/disposed`.
`updateConfig({selected:'custom:captain-diesel',visible:true})` вызывается только
кнопкой «Показать Капитана». Скрытие, размеры, выбранный питомец и положение
самовольно не меняются. Другой выбранный питомец реплик Дизеля не получает.

Публичный provider не поддерживает добавление текста в родной пузырь, поэтому
используется отдельный пузырь и кнопка «Реплика» рядом с существующим аватаром.
Его bounds считываются с `.dcp-floating .dcp-pet-button`. Чужой DOM не изменяется;
если аватар не обнаружен или скрыт, пузырь скрывается. При изменении DOM upstream
эта локализация может потребовать адаптации. `acquireDisplay()` не используется:
отрисовкой и уведомлениями пета продолжает владеть исходный плагин.

## Реплики и ограничения

66 заранее написанные русские реплики, восемь тем: морские байки, начало,
завершение хода, ошибка, ожидание решения, тесты, контекст, память.
Соседние реплики одной темы не повторяются. В покое чередуются байки и советы
по проверкам, контексту и памяти. Содержимое проекта/чатов и ошибки не читаются.

Состояния берутся из фактического `notifications.activity.pose` provider:
`running`, `waiting`, `failed`, `review`. Завершение озвучивается только после
наблюдавшегося начала данного сеанса, не из старого уведомления при загрузке.
Реплика о завершении означает только завершение хода, не успешный тест/деплой.
Пузырь не подтверждает инструменты и не подменяет штатные уведомления DSH.

Автоматические событийные реплики ограничены паузой 20 секунд; байки в покое —
настраиваемой паузой 30–1800 секунд (по умолчанию 180). Видимость текста 5–30
секунд (по умолчанию 12). В скрытом окне и при другом питомце байки не запускаются.
Кнопка «Реплика» выдаёт текст по запросу. Нет новых анимаций; reduced-motion
сохраняется. Подписки, таймеры и пузырь освобождаются при выгрузке.

## Настройки и API

Страница «Капитан Дизель»: включение реплик, автоматические реплики, интервалы,
выбор темы и локальный preview, редактор собственных реплик по темам, кнопка показа существующего Капитана. До 12 строк по 240 символов на тему; пустое поле возвращает встроенный набор. Overrides хранятся только у Капитана и не затрагивают Miara/Hiyori.
Настройки косметические, общие для установки; не привязаны к чату/проекту.
`ctx.dshHomePath('captain-companion')/config.json` хранит только строгую схему:

```json
{"schemaVersion":1,"enabled":true,"automatic":true,"intervalSeconds":180,"bubbleSeconds":12,"phrases":{}}
```

`GET /airules/captain-companion` читает конфигурацию, revision и CSRF token.
`POST` принимает `{config,revision}`, заголовки `content-type: application/json`
и `x-airules-csrf`. Проверяются штатный connection admission, CAS, типы, размер,
symlink/hardlink. Файл ограничен 32 КиБ, тело HTTP — 64 КиБ. GET не пишет файлы. Токен не сохраняется в конфигурации.
Чаты, модель, MCP, shell и approvals через этот API недоступны.

Код не вызывает модель/сеть кроме собственного локального API, не отправляет
сообщения и не добавляет инструкции в system prompt. Платных вызовов нет.

## Проверка

`node --test tests/captain-companion.test.mjs`: 11/11 PASS. Проверены 66 реплик,
anti-repeat, целевой пет, отсутствие исторического ложного завершения, cooldown,
idle/disabled/hidden, типы и границы настроек, CAS, symlink/hardlink, admission,
CSRF, body limits и отсутствие команд/чатов/нового аватара в клиенте.
UI-приёмка и установка выполняются владельцем release отдельно.
