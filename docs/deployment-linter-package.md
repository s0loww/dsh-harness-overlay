# Тестовый пакет DSH с локальным линтером — TEST2

Дата: 11 ноября 2026. Версия пакета: 0.17.2-test2, policy: 0.17.3-linter1, официальный host: 0.2.2-rc.1.

Пакет предназначен для закрытого тестирования коллегами. Личные аккаунты, проекты и история автора не включены. В приватной раскатке находятся общие учётные данные согласованных MCP; архив и его provisioning-файлы не предназначены для публикации.

## Что добавлено

- Portable Eclipse Temurin JRE 21.0.13+9 x64: отдельная установка Java не требуется.
- BSL Language Server 1.0.7: штатный редактор BSL, LSP-инструменты агента и CLI-анализ используют комплектный runtime.
- Изолированные настройки линтера и редактора в DSH_HOME. Проектный .bsl-language-server.json приоритетнее базового файла; существующие явные настройки сохраняются.
- Запуск WebSocket ограничен 127.0.0.1. Java не добавляется в системный PATH, системный JAVA_HOME не изменяется.
- Совместное применение с ранее собранными дополнениями, правилами, локальным Cognee, моделями и MCP. Проектные runners сохраняют свои явно закреплённые инструменты.

Приватный отчёт var/deployment-packages/build-test2-result.json: PASS. Итоговый ZIP — 3 567 622 498 байт (около 3,32 ГиБ); SHA256: b12305af59152bc7ef895f746a295f126aada77033b819d15e5d32ecc27e6d68. Рядом находится файл .zip.sha256.

Полная сверка 12410 файлов (3 919 632 640 байт) подтвердила manifest SHA256 935d77a6a0bc0a0affa6bddde811de331bdf1ed5d38e2e8e3d51c0aeff0b91a0. Предыдущий пакет TEST1 сохранён без изменений.

Внешний ZIP содержит вложенный payload/engine.zip: это позволяет сначала распаковать пакет стандартными средствами Windows, затем безопасно восстановить длинные пути комплектным Python. Для установки выбирайте короткий локальный путь, например D:\DSH, и запускайте Setup.cmd обычным пользователем. Docker Desktop/WSL при отсутствии устанавливаются отдельным шагом с необходимыми правами и возможной перезагрузкой.
