# Дальнейшие интеграции

## Трекеры проекта: YouTrack и Битрикс

Пользователь предложил позже встроить взаимодействие с Битриксом через API и спросил о YouTrack. Сейчас подключения и внешние операции не выполняются.

Предлагаемый общий интерфейс: проектная привязка трекера; чтение задачи/комментариев/вложений; связь с OpenSpec, планом и доказательствами; явная команда публикации отчёта/комментария/смены статуса. Настройки проекта отдельно от машинных секретов; MCP-фасад не обязателен.

- YouTrack: REST API, permanent token с правами пользователя; проекты, задачи, поля, комментарии и вложения. https://www.jetbrains.com/help/youtrack/devportal/youtrack-rest-api.html
- Битрикс24: входящий вебхук для личного подключения, OAuth для распространяемого приложения. https://apidocs.bitrix24.com/settings/how-to-call-rest-api/authorization.html
- Перед реализацией уточнить продукт: Битрикс24 или сайт/CMS «1С-Битрикс», облако/коробка, конкретные необходимые операции.

Внешние записи, сообщения и изменения статусов не становятся автоматически разрешёнными от самого подключения трекера. Текущие данные и учётные записи не импортируются из чужой сборки.
