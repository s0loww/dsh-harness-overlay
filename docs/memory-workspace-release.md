# Локальная память Cognee в рабочем DSH

Установлено 2026-11-10 на официальный Desktop `0.2.1-rc.5`:
UI `0.12.0-ui23`, policy `0.12.0-dev43`, canonical rulepack
`0.12.0-g89ba49d`. В rulepack 55 правил, 13 ролей и 53 навыка.

## Результат

В **Настройки → Контекст и история → Память проекта** доступны подключение,
документы текущего проекта, CHUNKS-поиск, состояние обработки и ограниченный
граф с документным происхождением. `airules_memory` встроен в наши пресеты
1С, Python и системного администрирования; Standard не получает этот инструмент.

Memoria остаётся основной рабочей памятью. Cognee — дополнительный backend;
автоматического выбора вместо Memoria, зеркала или переноса данных нет.
Общий portable навык `memory-workspace` применим к обоим backend и включён
в canonical airules, включая Codex-слой.

Cognee `1.6.7` работает отдельным Docker Compose в `D:\AI_Projects\cognee_local`.
Образ закреплён digest, порт только `127.0.0.1:18080`, хранилище и model cache
постоянные. Access control включён, DSH использует отдельного обычного пользователя.
Auth-off режим в исходной проверке дал межпроектную утечку и не используется.

Машинное подключение создано отдельно от артефакта:
`<DSH_HOME>/memory-workspace/config.json` и приватный `auth.json`.
Права каталога/ключа ограничены текущим Windows-пользователем и SYSTEM.
Ключ не возвращается UI или модели. При передаче сборки другому человеку
требуются его собственные сервер/подключение; наша авторизация не поставляется.

## Выполнение и границы

Из панели запись/обработка передаётся в выбранный чат и может вызвать выбранную
модель. Реальную мутацию выполняет инструмент внутри native turn с approval,
повторной проверкой scope/config/auth и разрешением на запись. Субагенты
читают, но не записывают память. Queued, uploaded, processing и completed
различаются; завершение проверяется по точному pipeline receipt.

CHUNKS проверяет dataset envelope и принадлежность исходных документов.
Граф — документно подтверждённый structural preview до 80 узлов/600 связей,
не полный semantic graph и не граф кода 1С. Журнал неопределённых операций
переживает restart, привязан к endpoint и не запускает слепой повтор.

Локальные GLiNER demo и английские embeddings работают без платного LLM API;
преимущество над Memoria на русской документации/1С пока не измерялось.
Загрузка произвольного файла из UI пока не реализована: текущий ввод — текстовая
подтверждённая заметка, а список показывает документы существующего набора.
