# Проектные настройки вместо выбора сеанса

Сборка: airules 0.16.0, Desktop 0.2.2-rc.1. UI `0.16.0-host022-ui1`, policy `0.16.0-dev4`.

Общий выбор проекта берётся из штатных рабочих областей DSH. Он применяется на всех страницах настроек и сохраняется отдельно от чатов. Несколько чатов одной рабочей папки представлены одним проектом. Новые чаты, запросы модели и разрешения автоматически не создаются.

## Штатное исполнение

Чат больше не является владельцем настроек. Его native-контекст нужен только для исполнения и проверки прав. Интерфейс подбирает его автоматически, закрепляет ID, корень и revision прав в конкретном запросе. При изменении проекта/прав запрос прекращается; read-only не заменяется более привилегированным чатом. Во время обновления контекста запись блокируется. Сам источник прав сохраняется штатным.

Проект не получает права через произвольную строку пути из браузера: принимаются только зарегистрированные рабочие области. Родительские/дочерние сеансы не смешиваются. Частный request lease повторно проверяет корень и права перед файловыми операциями. CSRF, CAS и штатные approvals остаются обязательными.

Общие настройки аккаунтов, моделей и программ остаются общими. История, выбор модели конкретного разговора, разрешения, genuine-user approvals, handoff, запущенные задания и адресат Telegram сохраняют свою настоящую принадлежность конкретной операции или разговору. Они не объединяются под видом проектных настроек.
