# Настройки DSH: UI dev9 / policy dev13

Установлено 2026-11-04 в официальный Desktop 0.2.1-rc.5.

## Что исправлено

- Подписки: HTTP 405 был следствием неактивного вложенного RPC-плагина.
  Native connection связывает маршрут с владельцем, которому нужен доступ к
  webServer. Регистрация теперь явно передаёт правильный Cordis Context.
- Kimi: используется native modifyRecord/deleteRecord, состояние подключения
  читается из configured. Ошибка загрузки больше не означает «подключено».
- Баланс: HUD обращается к deepseekAccount.getBalance через защищённый
  read-only маршрут; все используемые Cordis-сервисы объявлены явно.
  USD/CNY и пополненный/предоставленный баланс показаны отдельно.

## Организация интерфейса

Настройки сгруппированы по назначению. Единая страница «Провайдеры и модели»
содержит поиск, фильтр, обновление, сворачиваемые группы и карточки провайдеров.
Подключение подписок и API, аккаунт DeepSeek и настройка моделей используют
существующие native операции. Kimi убран из общих настроек. Старые разделы
провайдеров скрываются только при наличии новой страницы.

«Настройки проекта 1С» содержит совместимые поля .dev.env: база и подключение,
платформа и исходники, объекты/расширения и авторство. Проект выбирается через
native-сеанс. Сохраняются только изменённые поля; неизвестные параметры и
комментарии сохраняются. Пароли доступны только для записи, резервные копии
защищены ACL и лежат вне проекта в DSH_HOME/project-settings-backups.

Это совместимый набор проектных параметров, а не полный перенос окружения
Олега: обнаружение установленных баз, запуск Конфигуратора, проверки/deploy,
ротация моделей и модели для ролей требуют отдельной интеграции. MCP не
перенастраивается. Ранее исключённые блоки не возвращены.
