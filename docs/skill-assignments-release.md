# Назначения навыков для нашей оркестрации

Дата: 2026-11-05. Установлены UI dev15 / policy dev29, DSH Desktop 0.2.1-rc.5.

В разделе «Навыки», под карточками, доступны тип текущей задачи и редактор
назначений. Поддерживаются 13 типов: анализ, планирование, спецификация/OpenSpec,
архитектура, реализация, исправление ошибки, проверка по спецификации, ревью кода,
тестирование, итоговая проверка, документация, рефакторинг/производительность,
эксплуатация. Дополнительные оси — 13 канонических ролей и штатные режимы доступа.
Пустая ось означает «все».

## Оркестрация и runtime

Явный выбор типа задачи имеет приоритет. В «Авто» штатный режим планирования
выбирает planning; управляемый делегат получает тип из своей точной роли.
Обычный агент без определённого типа видит полный каталог. Родительский выбор
не наследуется ребёнком, тип не угадывается из текста переписки.

airules_delegate записывает `airules-role:<role>` в штатный descriptor запуска до
первого шага ребёнка. Контекст учитывает только собственный первый descriptor,
не унаследованный при fork. Старые делегаты без префикса получают полный каталог
либо явно выбранный тип. Штатный изолированный planMode читается через serviceFor.

Runtime действует в 1c-airules/python-airules/sysadmin-airules после штатной
подготовки шага. Он получает полный scoped snapshot, сохраняет native invocation
policy и заменяет только список описаний навыков. Инструкции по-прежнему загружаются
по запросу. Прямой вызов доступного skill(name), права и песочница не меняются.

Новая подборка добавляется при изменении состава; одинаковый список не дублируется.
Смена типа может расширить каталог обратно. Неполный снимок откладывает публикацию,
сохраняя принятую историю; повреждённые назначения показывают ошибку и оставляют
штатный каталог. Другие пресеты не затрагиваются.

## Настройки

Встроенные назначения для 18 наших навыков → общие переопределения
DSH_HOME/skill-assignments/settings.json → проектные .dsh/skill-assignments.json.
Неизвестные навыки не ограничиваются. Сброс удаляет выбранное переопределение;
наследуемое значение и другие записи сохраняются. Запись проверяет SHA-ревизию,
размер до 512 КиБ, пути без ссылок, сохраняет резервную копию.

Общие назначения требуют native full access, проектные — workspace-write. Выбор
типа текущей задачи является метаданными и возможен также в read-only, без
повышения прав. Он хранится отдельно для данного сеанса.
