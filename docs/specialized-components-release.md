# Специализированные компоненты DSH

Сборка сохраняет официальную оболочку DSH 0.2.1-rc.5 и нашу оркестрацию. Эта
итерация завершает специализированные панели и подключение оставшихся выбранных
семейств провайдеров. Новых запросов к платным моделям и реального деплоя нет.

## Состав

| Компонент | Реализация | Границы |
|---|---|---|
| Хранилище 1С | Проектные binding, планы, готовый bridge для repo-ops, native sandbox/approval, связанный отчёт | Внешний скрипт и его зависимости требуют явного доверия. Реальный прогон хранилища не сертифицирован |
| Обновление / AI merge | Двух-/трёхстороннее сравнение XML-выгрузок, таблица групп изменений, план CFE | Не выполняет MergeCfg/применение CFE и не определяет состояние поддержки |
| v8unpack | Готовый bridge для явно установленной версии Python/v8unpack, изолированный Python и проверка артефактов | Реальное преобразование не выполнялось; технический отчёт не доказывает загрузку файла платформой |
| Связи и операции | Фактический nodes/edges ответ MCP, разделение по session/root, ограничение объёма, native jobs | Не строит индекс кода или памяти; неполнота показывается |
| Долгие MCP-вызовы | Явно проверенные методы чтения, native scheduler с PTC parent, `job_output`, собственная отмена | Список пуст по умолчанию; shell policy не переписывается; remote cancellation не считается rollback |
| GLM / Qwen / OpenCode | Изолированные key-plan подключения через существующий native PiAiAdapter | Qwen International; один аккаунт, без заявленной ротации или квот |
| Google / Muse | Явно настроенные исполняемые файлы и версии, один штатный ACP adapter, собственное состояние входа | CLI не скачиваются и не запускаются при загрузке страницы. Сохраняются native BUILD/access/approvals |
| Cursor | Адаптер к отдельно установленному SDK 1.0.38, собственные credentials, native tool handoff | SDK не распространяется в артефакте. Требуется штатный режим внешнего агента и подтверждённое завершение перед handoff |

Прямой Claude subscription OAuth намеренно не объявлен рабочим: донор отключает
этот маршрут запросов. Карточка предлагает штатный Claude CLI через ACP либо
Anthropic API. Assistant DSH, голос, Jira, поддержка/обновление донора и Live2D
остаются исключены.

## Правила и навыки

Канонический airules `247add5cafab27c1fd705a679f40474604d8b07a` чисто собран как
`airules-0.12.0-g247add5`: 55 правил, 13 ролей, 52 навыка DSH (50 переносимых,
2 специфичных для DSH), 366 файлов. Коммиты `9601bbe` и `247add5` отправлены в
общий репозиторий.

Четыре новых переносимых навыка: `1c-repository-manage`, `1c-ai-merge`,
`v8unpack-cf`, `1c-element`. Их тела живут в общем airules; target contract и
назначения задач связывают их с DSH без копирования политики в сам интерфейс.
Объявление навыка не выдаёт права и не загружает все его инструкции на старте.

`cursor-provider-port.md`, `specialized-port-review.md` и

четырёхвариантный модельный прогон: пользователь отложил его до завершения сборки.

## Совместимость и найденные отказы

Полный профиль обнаружил старые peer ranges у LSP actions и composer-history.
LSP допускается ровно на rc.5 через engines.dsh; manifest и неизменённый entry
проверяются по SHA-256. Native proof подтверждает восемь scoped tools, но не
семантическую работу с реальным BSL LS. См. `onec-lsp-compat.md`.

Composer history получил чтение retained Chat projection вместо удалённого
Session.nodes, а также необязательное чтение отсутствующего projectPresetUi
через публичный Context.get. Обязательные пять native services сохранены.
Диагностическая отдельная копия воспроизвела настоящий Cordis error; готовый
клиент затем проверен через Ctrl+R. История/localStorage не мигрировались.
UI20/UI21 были отвергнуты реальным браузером и не устанавливались пользователю;
их точные старые байты разрешены verifier только по известным версиям для
подлинного отката, новые сборки требуют исправленный hash.

Унифицированная страница перестала повторно объявлять settings.models.sign-in:
владельцем остался native onboarding. Настройки и стрелки Turn Navigator
используют HTML select и текстовые стрелки вместо отсутствующих exports
primitives. Данные и исходные режимы навигации сохраняются.
