## Использование

В настройках «Интерфейс → Краткость ответов» можно выбрать текущий чат и режим
«Кратко (Lite)». По умолчанию он выключен; выбор не наследуется другими чатами.
Технические подробности, которые пользователь запросил явно, сохраняются.

«Контекст и история → Документы проекта» работает с относительными путями выбранного
проекта. Индексация использует локальный конвертер, кэш привязан к корню проекта,
хешу исходного файла и версии конвертера. Изменившиеся документы исключаются из поиска
до переиндексации. OCR отсутствует: сканированный PDF может требовать отдельного OCR.
Импортированное содержимое рассматривается как данные, а не инструкции.

Office использует portable runtime официального DSH; Codex, системный Python и
автоматическое скачивание программ не нужны. Для таблиц рендерится лист/диапазон,
для документов и слайдов — выбранные страницы. Вывод создаётся в новом пути проекта;
исходники не перезаписываются. Полученный PNG/PDF необходимо просмотреть.

В пресете 1С airules_capabilities возвращает реальные scoped schemas без выполнения
найденных инструментов. Фасад необязателен: прямые MCP и проектные runners остаются
самостоятельными возможностями. airules_debug_case хранит гипотезы и хеши доказательств
в проектном notebook внутри DSH_HOME. Он не изменяет BSL, не ставит пробы, не запускает
ИБ и не выдаёт запись модели за подтверждённый результат проверки.

Новые инструменты соблюдают штатные права и песочницу DSH. Standard не получает
новых инструментов и наших scoped skill providers; штатные Office skills Desktop
в нём сохраняются. MCP, учётные записи и параметры проектов не импортируются.
