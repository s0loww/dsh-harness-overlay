# Проверки и деплой — policy dev25

Дата: 2026-11-05. Установлены UI dev14 / policy dev25 для DSH Desktop 0.2.1-rc.5.

Выбор сценария работает и до создания проектной конфигурации. Доступны шаблоны
проверок, деплоя и безопасного fixture. Кнопка «Сохранить сценарий в проект»
действительно записывает конфигурацию с проверкой версии, резервной копией и
сохранением существующих сценариев. План полного 1С-сценария:
doctor → analyze → deploy-preview → deploy-apply.

Исполнитель поддерживает файловую и серверную базы test/development, проверяет
точную версию платформы, профиль, исходники, цель и связанный отчёт runner.
Проектный runner выполняется через штатные права и песочницу DSH. MCP-фасад
не требуется. Проверенный комплект agent-1c включён в пакет для передачи сборки.

Режимы disabled, fixture-only и enabled переключаются отдельной кнопкой сохранения.
Выбор сохраняется в `dshHome/workflows/executor-settings.json` и переживает перезапуск;
смена режима не выполняет сценарий и не меняет права песочницы. Администратор
может запретить изменение режима через allowModeConfiguration:false.

При неопределённом результате блокировка цели сохраняется. Восстановление требует
подтверждения остановки исполнителя и доказательства состояния цели; исходный
результат остаётся в журнале. Поддержаны fixture, отдельно проверенный локальный
PowerShell recovery runner и необязательный настроенный MCP recovery provider.
Реальные recovery providers автоматически не подключаются.
