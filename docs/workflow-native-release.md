# Проверки и деплой: штатная интеграция DSH

Дата: 2026-11-04. Установлено в DeepSeek Harness Desktop `0.2.1-rc.5`:
UI `0.1.0-dev14`, policy `0.12.0-dev17`.

## Что работает

- Раздел настроек **«Проверки и деплой»**: выбор проектного сеанса и workflow,
  доступные операции и причины блокировки, формирование плана, история и результаты.
  Планирование не запускает процессы. Исполнение доступно агенту через штатные tools;
  HTTP-интерфейс не предоставляет запуск и отмену.
- Права берутся из текущего сеанса DSH. Процессы идут через native
  `sandboxPolicy`, `sandbox` и `subprocess`; обхода ограничений и автоматического
  повышения прав нет. Отмена использует управляемое завершение собственного процесса.
- Инструменты подключены к пресетам 1С, Python и системного администрирования.
  Стандартный пресет их не получает. Для планирования и запуска требуется сеанс
  с разрешением записи; просмотр статуса доступен отдельно.
- Данные проекта читаются из `.airules/workflows.json`. В сборку не включаются
  адреса MCP, секреты, базы и персональные проектные привязки. Образец конфигурации:
  [README интеграции](../src/workflow-integration/README.md).
- Адаптер `agent-1c` проверяет профиль и исходники runner, формирует фиксированные
  PowerShell-команды. В этом выпуске разрешены только `doctor` и `analyze` для
  проверенного набора исходников runner. Хешируется весь объявленный кодовый набор;
  изменённый или неизвестный runner не получает автоматического доверия.
- Адаптер TestEnv распознаёт фиксированный вход unit-тестов и его зависимости,
  но запуск остаётся заблокированным: такой сценарий изменяет тестовую базу.
- Мост MCP использует уже зарегистрированные инструменты DSH и их штатные права.
  Машинный список разрешённых операций по умолчанию пуст. Поддерживаются только
  нормализованные отчёты `assertions-json` и `test-summary-json`; для произвольных
  ответов серверов нужны отдельные преобразователи. Фасад не обязателен.

## Границы выпуска

Реальный deploy выключен (`allowTargetMutations: false`). Unit/UI-тесты с записью
в базу, lifecycle тестовой среды, backup/restore и deploy/apply не включены.

build и вид исходников пока берутся из явно заданных данных, а не из live-пробы.
Привязки рабочих проектов не создавались. Сценарий BKI не выполнялся.
