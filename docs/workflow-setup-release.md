# Исправление настройки проверок — policy dev19

2026-11-04. Установлено: UI dev14 / policy dev19, официальный host rc.5.

## Причина

Предыдущая страница была техническим каркасом. Она требовала вручную создать
проектный binding, не предлагала способа настройки и показывала неработающую
кнопку «Деплой отключён». Это скрывало реальную границу: исполнитель применения
изменений в базу ещё не реализован. Запрет реального запуска пользователем
не означает запрет разработки исполнителя; прежний отчёт о готовности был шире
фактически реализованного подмножества.

## Исправления

- Мастер «Найти инструменты проекта»: безопасное обнаружение фиксированных
  agent-1c/TestEnv путей и допустимых фактов профиля.
- Форма с видом исходников, именем расширения, точным build платформы и каталогом
  исходников. Подготовка конфигурации с проверкой профильных фактов и всего кода
  runner, без записи и исполнения. sourceDir должен совпадать с каталогом snapshot.
- Готовые конфигурация и запрос агенту на сохранение через обычные права DSH.
  Существующий файл предлагается сравнить и объединить, а не заменить автоматически.
  Мастер не выдаёт доверия runner и работает даже при повреждённом текущем binding.
- Конкретные причины блокировки и готовый запрос агенту после формирования плана.
- Готовность шага учитывает проверку версии runner и наличие PowerShell. Ранее
  наличие descriptor ошибочно выглядело как готовность к исполнению.
- Вместо фиктивного переключателя деплоя показана фактическая граница реализации.

Для проекта без поддерживаемого runner мастер сообщает, какие входные точки
поддерживаются. Он не устанавливает инструменты и не создаёт фиктивно готовый pipeline.
TestEnv остаётся доступным для обнаружения, без генерации сценария изменяющих базу тестов.

Предварительный кандидат 10 использовался для визуальной проверки и локальной

**Реальные проектные runners, MCP, тесты баз и деплой в этой работе не запускались.**
Полноценное исполнение deploy/apply и изменяющих базу тестов остаётся отдельной
незавершённой частью механизма; данный выпуск исправляет настройку и видимость
состояния, но не включает эти операции.
