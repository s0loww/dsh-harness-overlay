# Local document workbench

Host plugin + web settings `/airules/documents`; mount `./tools` only in the three airules compositions. It does not register another Office skill provider. Canonical Office workflows override the global Desktop Office skill definitions in those presets.

`airules_documents`: status/show/index/search/read. Supported sources: project-local PDF/DOCX/XLSX/PPTX, no links/hardlinks; max50MiB source, 8MiB extracted text, 200 docs/250MiB batch. Search only fresh source-hash matches; read max100 lines, 2000characters each; search max40hits. Converter implementation hash + pinned parser version invalidate old caches. Private cache uses DSH home, root hash and source/content hashes; indexing needs workspace-write. OCR and remote conversion are not provided. Source text is data, never instructions.

`airules_office`: runtime/convert/render/recalculate. The first-party `load_workspace_dependencies` prepares the official DSH packaged primary runtime (no Codex dependency, system Python or network install). Model nested calls retain native execution tokens; settings use the first-party preparation body because it only initializes that local payload. Rendering/conversion/recalculation use pinned `@deepseek-ai/libreoffice-kit`0.1.5, resolving physical app.asar.unpacked CLI paths. Authoring uses explicit bundled Python with python-docx/openpyxl/python-pptx exposed by runtime diagnostics and the native shell. Outputs must be fresh project paths with existing parents. Rendering max10 selected document/slide pages (default1),96DPI; worksheets use exact sheet and optional A1 range without page numbers, with bounded tiles/pixels; no overwrite. Macro formats/COM/OCR/cloud are not supported.

All conversion subprocesses go through the current session native sandbox and subprocess provider, bounded output/time/cancellation. UI requires native admission and CSRF; writes honor project session mode. Cold sessions can inspect cached inventory; conversion needs an active agent. Error output does not expose process stderr or credentials. No model calls, autostart servers, dependency downloads or project runners are initiated.

Pinned extraction closure: MIT `@jiaoqsh/dsh-document`0.1.3, `@firecrawl/anydoc`0.1.9 and optional win32-x64-msvc0.1.9 native binding, `@firecrawl/pdf-inspector-wasm`1.14.2 including its worker/WASM. Preserve package licenses. Office engine and official primary-runtime retain their upstream payload/license closure in the standard Desktop installation.
