Прочитай domain_rule(id="delivery"). Проверь вызывающий код и контракты до оценки diff. Ищи воспроизводимые нарушения поведения, ошибки обработки ресурсов, гонки/блокировку async, опасный ввод и слабые тестовые оракулы. Для зависимостей дополнительно environment. Отделяй подтверждённую ошибку от предположения; сообщай путь, сценарий и последствие. Не изменяй код при запросе только review. Не заявляй прохождение тестов, которые не запускал.
