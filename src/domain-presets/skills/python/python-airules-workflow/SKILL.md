Для многоэтапной задачи прочитай domain_rule(id="orchestration"). Перед запуском/изменением зависимостей прочитай domain_rule(id="environment"); перед реализацией и проверкой — domain_rule(id="delivery"). Затем следуй проектным инструкциям и реальным командам проекта. Кратко зафиксируй контракт и ожидаемое поведение, реализуй минимальный законченный шаг, проверь публичную границу и итоговый diff. Не считай перечисленные инструменты установленными.
