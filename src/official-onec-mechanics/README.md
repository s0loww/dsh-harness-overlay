# Official 1C mechanics

Безопасный механический слой пресета `1c-airules` для официального DSH:

- дерево XML/EDT и редактор BSL/XML через адаптированный MIT `dsh-bsl-editor`;
- LSP actions/diagnostics через Apache-2.0 `dsh-lsp-actions` только при наличии локально установленного BSL Language Server;
- локальное распознавание корня проекта без зависимости от Oleg bundle, MCP и состояния проекта;
- документированный минимальный контракт локальных настроек проекта.

BSL Language Server не поставляется в артефакте. Укажите `ONEC_BSL_LS_COMMAND`
и, при необходимости, JSON-массив `ONEC_BSL_LS_ARGS`. На Windows также
распознаётся стандартная установка в `%LOCALAPPDATA%\Programs\bsl-language-server`.

Полный мастер проектов намеренно не портирован: его реализация связана с Oleg
Full policy, MCP-конфигурацией и операциями подготовки/изменения базы. Этот
пакет не создаёт, не восстанавливает и не загружает базы.
