# Контекст проекта

## Назначение

Опишите назначение текущего проекта по его README и инструкциям пользователя.
Не предполагайте язык разработки, отрасль или внешние сервисы.

## Соглашения

- Артефакты OpenSpec пишутся по-русски, если пользователь не выбрал другой язык.
- Структурные заголовки и ключевые слова SHALL/MUST остаются на английском.
- Имена команд, путей и переменных не переводятся.
- Задачи изменения ведутся в `openspec/changes/<change>/tasks.md`.
- Сохраняются текущие разрешения действий, PLAN и обычные подтверждения инструментов.
- Секреты и учётные данные не попадают в артефакты.
