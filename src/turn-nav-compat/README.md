# Навигатор ходов на rc.5

В закреплённом clean client `dsh-turn-navigator@0.4.3` используются старые
`Menu` / `IconChevron*Outline14`. В текущих primitives часть этих экспортов
отсутствует: вклад настроек падает с React error 130.

Адаптер проверяет точный SHA-256 clean client и меняет только UI представление:
обычный HTML select для тех же трёх режимов, текстовые стрелки в существующих
кнопках. Состояние, подписи, обработчики навигации, ключи и формат browser-local
preference сохраняются. Недоступный импорт primitives после этого не нужен.

Преобразуется только builder-owned copy перед запечатыванием нового артефакта.
Исходник, ранее выпущенные артефакты и данные пользователя не переписываются.
